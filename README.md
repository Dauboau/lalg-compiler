## Como executar

1. Abra o terminal na pasta `lalg_compiler`

2. Compile o projeto:
```bash
mvn clean compile
```

3. Execute o compilador passando o arquivo de entrada:
```bash
mvn exec:java -Dexec.args="programa_1.lalg"
```
